# CleanDrops

This Palworld mod removes a large number of unnecessary item drops from Pals and human enemies, reducing inventory
clutter and making loot collection cleaner.

Steam Workshop URL: https://steamcommunity.com/sharedfiles/filedetails/?id=3770317667

## Features

- Removes common resource, food, ammunition, equipment, and material drops.
- Keeps inventories cleaner by preventing unwanted items from appearing in enemy loot.
- Applies to drops from both Pals and humans. Chest loot tables are not affected.

## Note on level 1

If you use this mod from level 1 you will need to get wool, pal fluids and organs from vendors, chests or ranching.

This makes the start of the game a bit more difficult, though in my opinion also more interesting.

## Installation

1. Install from Steam Workshop with dependencies
2. Start the game
3. Go to Settings -> Mod Management
4. Enable UE4SS, PalSchema and CleanDrops
